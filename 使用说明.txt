任务栏开关
==========
1. 解压整个文件夹，双击“任务栏开关.vbs”隐藏任务栏。
2. 再双击同一文件，退出并恢复任务栏及原自动隐藏设置。
3. Shift+F1：临时显示 / 再次隐藏。
4. Ctrl+Alt+Q：退出并恢复。

请把脚本放在同一目录。目录可以移动。
需要 Windows PowerShell 5.1 和 Windows Script Host / VBScript。

自启：Win+R → shell:startup，在该文件夹中创建指向 hide-taskbar.vbs 的快捷方式。
不要只复制 vbs 文件。取消自启时删除快捷方式。
卸载前先正常退出，再删除程序目录和自启快捷方式。

详细环境要求、异常恢复及验证方法见 README.md。
